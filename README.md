# cuestionario_bombas
Aplicación web estática para la evaluación interactiva de conceptos fundamentales de Análisis Técnico de Bombas Hidráulicas, basada en el material docente del Ph.D. Juan Sandoval H. (Mecánica de Fluidos).

📌 Características

🎯 10 Preguntas Evaluativas: Cobertura de temas clave (Ecuación de Euler, Leyes de Afinidad, Cavitación, NPSH, BEP y clasificación de bombas).

📐 Fórmulas Matemáticas: Renderizado con KaTeX.

🖨️ Exportación PDF / Impresión: Formato optimizado para entregar reportes impresos o digitales.

💾 Descarga de Datos: Exportación del cuestionario en formato JSON.

⚡ Sin dependencias backend: Listo para desplegar gratis en GitHub Pages.

🚀 Despliegue en GitHub Pages

Sube los archivos (index.html y README.md) a la raíz de tu repositorio en GitHub.

Ve a Settings > Pages en tu repositorio.

En Source, selecciona la rama main (o master) y la carpeta /root.

Haz clic en Save y tu enlace estará disponible en pocos minutos.
